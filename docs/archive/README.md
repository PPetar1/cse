# Archive

Point-in-time visuals that are useful to look at but not worth maintaining
per change. Unlike the docs listed in CLAUDE.md's documentation map, nothing
in this folder is updated as part of normal task work.

- `architecture-diagram.html` — a visual snapshot of the layered architecture
  (interface / session / game / core+procedures) plus a handful of the
  non-obvious "field notes" from `docs/architecture.md`, as of 2026-07-25.
  **Update only on explicit request** — it will drift from the real
  architecture over time, and that's expected. Open it directly in a
  browser to view.
