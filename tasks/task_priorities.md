# Task priorities

The ordered work queue: the agent takes the topmost unchecked task and
works down. Task files not listed here are backlog — visible in `tasks/`,
but not to be picked up until they're added here.

Format: one line per task, checked off when done, e.g.

```
- [ ] some-task.md
- [x] a-finished-task.md
```
